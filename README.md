# 🌐 Etenesh Gishamo - Portfolio

Welcome to my personal portfolio website!  
Built with **React, TypeScript, and Vite**, this site showcases my skills, projects, and experiences as a passionate **full stack web developer** with an interest in **AI and education technology**.

---

## ✨ Features

- 🎨 Clean and modern responsive design
- 👩‍💻 About Me section with background, skills, and interests
- 📂 Projects showcase with links to live demos and GitHub repos
- 📬 Contact form and direct links to my socials

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS, Mantine UI
- **Hosting:** Vercel
- **Version Control:** Git & GitHub

---

## 🚀 Getting Started

### Clone and run locally

```bash
git clone https://github.com/EteneshJeg/portfolio.git
cd portfolio
npm install
npm run dev
```
